    Each series is divided by its value at the start of the range and multiplied by 100, so 112 means up 12% since then. Stocks are daily closes in cedis; bonds and bills are their closing yield, so a yield rising from 20% to 22% reads 110; currencies are cedis per unit at the Bank of Ghana mid, so a rising line is a weakening cedi. GSE-CI is the simulated, equal-weighted index. Hover for each series' actual value.

    Correlation of changes, not levels: returns for stocks, the index and currencies, and the change in yield for bonds and bills. Thinly traded stocks go days without a trade, and their carried-over close would show as a run of zero returns followed by the whole move at once, so each pair is measured only between days both traded: both changes then cover the same span. The small figure is how many such changes each cell rests on; below 20 it shows —. Weekly uses each series' last trade of the week, for names too thin even for that.
